ChatGPT 활용 내역
이번 웹 프로그래밍 과제를 수행하면서 ChatGPT를 주로 JavaScript 문법과 기능을 이해하기 위한 학습 보조 도구로 활용하였다.
코드를 작성하는 과정에서 익숙하지 않은 함수나 메서드가 등장하면 해당 기능의 역할과 사용 방법을 질문하고, 이해를 돕기 위한 간단한 예시를 확인하였다. 예를 들어 배열의 filter(), sort() 등의 메서드와 localeCompare(), toLocaleString(), includes() 등의 사용법을 알아보았다.
또한 TMDB API를 활용하는 과정에서 API 응답 데이터의 구조와 각 속성의 의미, 데이터를 화면에 표시하기 위해 가공하는 방법 등에 대해 질문하였다. 이외에도 JavaScript의 조건문, 반복문, 함수, 객체 및 날짜 객체의 사용법 등 과제를 진행하면서 필요한 개념들을 찾아보았다.
ChatGPT의 설명과 예시를 참고하여 각 기능의 동작 원리를 이해하고 실제 코드에 적용하였으며, 이를 통해 새로운 문법과 기능을 익히고 과제를 보다 원활하게 진행할 수 있었다.
